# Assignment 5 - C++ Project

This is a C++ project for CSC252 Programming in C.

## Project Structure

```
Assignment5_Project/
├── src/              # Source files (.cpp)
│   └── main.cpp      # Main program entry point
├── include/          # Header files (.h, .hpp)
├── build/            # Build artifacts and executables
├── Makefile          # Build configuration
└── README.md         # This file
```

## Building the Project

To build the project:
```bash
make
```

To run the project:
```bash
make run
```

To clean build artifacts:
```bash
make clean
```

## Development

Add your source files to the `src/` directory and header files to the `include/` directory. Update the Makefile if you add new source files to the project.
